# Astro/physics Textbook List
A list of recommended/suggested textbooks for topics in astro/physics.

The majority of these have been taken from [this list that Lee Robbins (who was the astro/physics librarian at the University of Toronto) compiled from recommendations given by "graduate students, postdocs and faculty in the Department of Astronomy and Astrophysics, Dunlap Institute and CITA"](https://www.astro.utoronto.ca/AALibrary/recommendations.html)
